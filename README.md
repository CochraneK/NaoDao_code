## What this repository contains

The repository is intentionally small:

- `clean_pro.R` — the main data-cleaning script;
- `README.md` — project overview;
- `LICENSE` — repository license.

## Purpose

Use this project as a compact preprocessing step for online experimental or survey data exported from NaoDao before downstream statistical analysis.

> [!NOTE]
> Cleaning assumptions should be checked against the schema and export format of the specific NaoDao study before reuse.
